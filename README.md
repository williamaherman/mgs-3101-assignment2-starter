# MGS 3101 Assignment 2 Starter

This repository provides starter materials for Assignment 2: Exploratory and Descriptive Analytics.

## Included Materials

- `data/Sales-Export_2019-2020.csv` — the provided coffee shop sales dataset
- `assignment2_exploratoryAnalysis/` — the location for student work

## Dataset Notes

The CSV has columns: `country`, `order_value_EUR`, `cost`, `date`, `category`, `customer_name`, `sales_manager`, `sales_rep`, `device_type`, `order_id`.

`order_value_EUR` and `cost` are useful numeric fields. `country`, `category`, and `device_type` are useful categorical fields.

## Repository Expectations

Students should copy the starter materials to their own assignment repository and complete their analysis there.
